# Editor

개발 환경과 편집 흐름을 정리합니다.

현재는 Neovim 설정을 중심으로 관리합니다. 설정 자체는 [`neovim-setup.md`](./neovim-setup.md)에 기록하고, 실제 작업 중 반복해서 사용하는 조작 흐름은 [`neovim-workflows.md`](./neovim-workflows.md)에 분리해 둡니다.

## 문서 목록

- [Neovim 설정 스냅샷](./neovim-setup.md)
  - 현재 사용 중인 플러그인, LSP, 자동완성, Treesitter, Mason 관리 도구를 정리합니다.
  - Go 중심 설정에서 Go + Solidity + 문서 작성 + 리뷰용 설정으로 확장된 현재 상태를 기록합니다.
  - 플러그인을 더 추가하기보다, 실제 로컬 설정과 문서가 어긋나지 않도록 관리하는 데 초점을 둡니다.

- [Neovim 사용 흐름 메모](./neovim-workflows.md)
  - 정의 이동과 복귀, Git diff 확인, 코드 검색, 복사/붙여넣기, Markdown preview 같은 반복 조작 흐름을 정리합니다.
  - 키 목록 자체보다, 작업 상황에서 어떤 조작을 선택하는지와 왜 그 키로 기억하면 되는지에 초점을 둡니다.
